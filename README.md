# anubis-mcp-server-phone

This is a MCP server that is installed on a smartphone to enable app-use, data analysis, and calling

# What this is: 
## This is an MCP server that is a native IPHONE application that allows for the connection to the NeuralNexus to control and use apps on the user's behalf.
- Andriod/Iphone MCP server to control app-use
- Connects to the NeuralNexus to allow for an LLM to interact with your phone

I need to perform MCP iphone/android use to use a phone with MCP (app use) there is a frontend LLM that will hold a conversation with a user and the avatar will use this connection with the phone to use apps on the user's phone on the user's behalf.
